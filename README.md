# Nafasi MVP — Make your money last

This is an early, client-side prototype for a private money-planning companion aimed at people in Kenya with irregular income.

## Files
- `index.html` — the app. It can run locally in a modern browser.
- `README.md` — this guide.

## Run it locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Try the fictional sample figures. Use made-up numbers when demonstrating it.

## Privacy and limitations
- The calculations are performed in the browser.
- This version does not use an app backend, accounts, analytics, or external APIs.
- It does not save the user's plan. Refreshing can reset entries.
- A website host may still receive normal technical request information such as IP address.
- This is a prototype, not financial advice or a published financial service. Test calculations, accessibility, privacy behaviour and legal requirements before public launch.

## Publish with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a new public repository, for example `nafasi-mvp`.
3. Upload `index.html` and `README.md` to the repository root.
4. Open **Settings → Pages**.
5. Under build/deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish and copy the URL shown in Settings → Pages.

The URL will generally look like `https://YOUR-USERNAME.github.io/nafasi-mvp/`. This is an example format, not a working URL until you publish it.

## Before a real launch
- Review Kenya's applicable data-protection requirements and hosting disclosures.
- Do not add trackers or third-party scripts without assessing privacy implications.
- Test calculations, date handling and edge cases.
- Add a clear contact/support route and a proper privacy notice before collecting any user data.
